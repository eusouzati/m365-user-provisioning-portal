# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolhedor e construtivo. Assédio, discriminação ou ataques pessoais não são tolerados.

Para relatar condutas inadequadas, abra uma issue marcada como `conduta` ou entre em contato com os mantenedores pelo perfil do GitHub. Os relatos serão tratados com confidencialidade.
