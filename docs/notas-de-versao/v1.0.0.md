# Portal de Provisionamento de Usuários Microsoft 365 — v1.0.0

Primeira versão estável. O portal automatiza a entrada e a saída de colaboradores no Microsoft 365 a partir dos pedidos do RH, com aprovação, acesso inicial seguro, auditoria e LGPD — e sem nenhum segredo (Managed Identity e OIDC).

**Documentação completa (PDF, 25 páginas):** anexada a este release e em [`docs/Documentacao-Portal-Provisionamento-M365.pdf`](https://github.com/eusouzati/m365-user-provisioning-portal/blob/v1.0.0/docs/Documentacao-Portal-Provisionamento-M365.pdf).

## Destaques

- **Admissão:** formulário do RH com login gerado e conferido no Microsoft 365, aprovação por outra pessoa, conta criada **desativada**, licença na véspera e ativação no dia da admissão.
- **Primeiro acesso:** o gestor gera um código de uso único (Temporary Access Pass), exibido uma só vez; o colaborador cadastra senha e MFA.
- **Desligamento:** bloqueio no último dia no horário definido, sessões encerradas, saída dos grupos e licenças; a conta nunca é excluída.
- **Controle:** segregação de funções, perfis de onboarding validados, trilha de auditoria somente de acréscimo, exportação para Excel, anonimização LGPD.
- **Interface:** visual no estilo Microsoft 365, tema claro/escuro, celular, linguagem simples.
- **Operação:** agendador de hora em hora, painel do administrador, publicação automática com GitHub Actions + OIDC.
- **Segurança:** revisão de ponta a ponta na v1.0 ([docs/SEGURANCA.md](https://github.com/eusouzati/m365-user-provisioning-portal/blob/v1.0.0/docs/SEGURANCA.md)), CodeQL, cobertura mínima de 85%, `pip-audit` e gitleaks no CI.

## Como começar

1. Leia o [guia de implantação](https://github.com/eusouzati/m365-user-provisioning-portal/blob/v1.0.0/docs/IMPLANTACAO.md) e o [checklist de produção](https://github.com/eusouzati/m365-user-provisioning-portal/blob/v1.0.0/docs/CHECKLIST_PRODUCAO.md).
2. Implante primeiro em laboratório, com o modo simulação ligado (padrão).

## Atualizando a partir de uma versão 0.x

- Rode `Deploy-Infrastructure.ps1` uma vez para aplicar os novos ajustes de segurança do App Service e do Storage (nada é excluído; o script mostra o plano e pede `SIM`).
- Nenhuma permissão nova no Microsoft Graph.
